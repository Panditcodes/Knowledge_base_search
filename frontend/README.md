# Frontend (Vite + React + TS)

This folder contains the React frontend built with Vite, TypeScript, Tailwind CSS, Radix UI, and shadcn/ui.

## Local development

Prerequisites:
- Node.js 18+

Steps:
```sh
npm install
npm run dev
```

The dev server runs by default on http://localhost:8080 and proxies API requests to the backend via `/api` (see `vite.config.ts`).

## Build

```sh
npm run build
npm run preview
```

## Technology
- Vite
- React + TypeScript
- Tailwind CSS
- Radix UI + shadcn/ui
